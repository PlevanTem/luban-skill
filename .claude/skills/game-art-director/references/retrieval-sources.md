## 1. 行业 critique / 设计哲学

- **GDC Vault — Art Direction Bootcamp / Summit 历年** — https://www.gdcvault.com/?cat=10
  - 何时调用: 寻找 critique standard / pitfall 案例 / 0→1 decision framework
  - 核心 talks: "Studio Art Direction: What I've Learned" (pitfall list), "Pre-Production: The Lies We Tell", "Art Direction is Not Just Googling Images", "Building a Visual Identity"
- **Riot Games "Complementary Visual Design in Spirit Blossom"** — https://www.riotgames.com/en/news/complementary-visual-design-in-spirit-blossom
  - 何时调用: 找 0→1 visual identity 工作样本 / IP grounding 实操
- **Riot Games artedu — Intro to Game Art / Concept Art** — https://www.riotgames.com/en/artedu/intro-to-game-art
  - 何时调用: 引用工业标准化语言 (shape / color / detail)

## 2. Style guide 公开样本
