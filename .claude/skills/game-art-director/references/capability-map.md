## 1. Domain knowledge（视觉系统的工作原理）

### 1.1 风格 / Style DNA
- Can articulate a game's visual DNA in 3-7 keyword form (例：Spirit Blossom 的 "whimsical, spiritual, elegant, peaceful, abstract, beguiling") [来源: rsb]
- Knows the difference between a "mood" (情绪) and a "style" (风格) — 用户经常混用，专家区分 [来源: rsb, sig]
- Can identify when a project lacks a north-star concept phrase (e.g., "spirits interconnected in the spirit realm living in relative peace") and refuses to proceed without one [来源: rsb]

### 1.2 视觉系统三轴分解
- Can decompose any reference into shape / color / texture three-axis systems separately, not merge into "vibe" [来源: rsb]
- Knows shape language carries intention budget — geometry vs organic vs hybrid have different reading weights [来源: rsb]
- Can specify how depth is achieved (watercolor surface vs flat color vs PBR shading) — not just hue picks [来源: rsb]

### 1.3 IP grounding 机制
- Can extract foundational design tokens from existing IP assets (例: "use folklore patterns from Yasuo's shirt as base elements") rather than from-scratch new system [来源: rsb]
- Knows when a project must inherit IP DNA vs when it's free to depart (新 IP / 子系列 / 同系列扩展) [来源: rsb]

### 1.4 美术工业流程认知
- Understands the 2D concept → 3D translation pipeline well enough to spec what concept art needs to enable downstream production [来源: sig (Naughty Dog scope)]
- Knows the difference between Character AD, Environment AD, Tech AD scope; can hand off correctly [来源: sig (Riot JD spread)]
- [unverified] Familiar with current real-time rendering constraint horizons (PBR / lumen / nanite-class) enough to write concepts engine teams won't reject

## 2. Methods & frameworks（0→1 定调方法）

### 2.1 关键词驱动的方向定锚
- Can extract 3-7 thematic keywords from the narrative team (not invent yourself) [来源: rsb]
- Can pressure-test each keyword: "if I removed this word, would the visual brief still hold?" [来源: rsb]
- Knows the trap of mood-board-first design (image collage without keyword discipline) [来源: sig (Wayline + GDC "not just Googling")]

### 2.2 Style guide 早期产出
- Can produce a v0.1 style guide **while** 风格还在迭代——不等定下来再写 [来源: sig (Polydin step 2)]
- Can specify shape vocabulary / color principles / texture method in <1 page (not 50-page tome) [来源: sig + rsb]
- Writes "DO" examples and "DON'T" examples side by side (例: Riot VFX style guide 的反例页) [来源: sig (VFX style guide)]

### 2.3 Review / critique 标准化
- Can run an art review where critique is **on the work**, not on the artist [unverified]
- Provides constant feedback as the work iterates, not only at milestone gates [来源: sig (Naughty Dog AD scope)]
- Distinguishes "this is off-style" (具体) from "this doesn't feel right" (vibes — 自己 fail) [unverified]

### 2.4 复杂度与差异化平衡
- Can locate a project on a 2-axis chart: visual complexity (高/中/低) × visual distinctiveness (高/中/低) and argue the right cell [来源: sig (Wayline 4 dim)]
- Refuses to recommend "moderately complex + low distinctiveness" combinations — that's the homogenization trap [来源: sig (Wayline)]
- Knows the trade-off between production cost and visual ambition for the team's actual size/budget [来源: sig (Polydin pitfall #1)]

### 2.5 跨部门协同
- Can write a brief that game design / programming / audio teams can each act on without translation [来源: sig (Polydin duty #3)]
- Knows the visual language must guide gameplay (interactive object signaling, level navigation cues) [来源: sig (Polydin principle)]

## 3. Tools & artifacts（产出物）

### 3.1 Style guide / Art bible
- Writes Style guide v0.1 含: keyword cluster, shape vocabulary, palette principle (not just hex codes), texture method, DO/DON'T examples [来源: rsb + sig]
- Maintains it as a living doc — version-bumps when phases change, doesn't freeze at v1.0 [unverified]
- [unverified] Style guide 包含 silhouette readability test 标准

### 3.2 Concept review artifacts
- Maintains a curated reference board with keyword tags per image (not raw Pinterest dump) [来源: rsb (mood board approach)]
- Writes review notes in 3-bullet format: what works / what's off-style / specific change [unverified]
- Mark-up screenshots / paint-overs with shape & value adjustments (not just verbal notes) [unverified]

### 3.3 Cross-team artifacts
- Visual pillars one-pager: 3-5 pillars, each with positive example + negative example + acceptance criteria [来源: sig (Polydin step 2)]
- "Vertical slice" art handoff: a 5-10 image set proving the style at production quality, including silhouettes / hero shots / scale moments [unverified]
- [unverified] Engine team handoff doc specifying which shader features the style depends on

## 4. Judgment & taste（无法 codify 的判断）

### 4.1 风格 distinctiveness 判断
- Can predict whether a style will read as "X-game" or "generic indie" at 1-second silhouette glance [来源: sig (Wayline distinctiveness)]
- Calls out homogenization to industry trends (e.g., generic pixel-art, generic Studio Ghibli mimicry, generic ArcaneⓇ stylization) before they lock in [来源: sig (Wayline)]
- Knows when a style is unique-but-incommercial (太冷门会失去 market) vs unique-and-commercial (Hollow Knight / Cuphead) [来源: sig]

### 4.2 IP 一致性嗅觉
- Can detect IP drift in a single character concept review (e.g., "this silhouette doesn't feel like our world") within 2 minutes [来源: rsb (IP grounding)]
- Distinguishes "evolving the IP" (有意识) from "diluting the IP" (无意识) [unverified]

### 4.3 反 reference-driven design
- Refuses "we'll just look like X game" as a brief — that's not direction, it's mimicry [来源: sig (GDC "not just Googling")]
- Insists on at least one principle the project does **differently** from its reference cluster [来源: sig (Wayline 立场)]

### 4.4 情绪 / 叙事对齐
- Can articulate the emotional arc the visual system supports (例: "wonder → loneliness → reunion") and verify each visual choice maps to a beat [来源: sig (Polydin "emotion drives recognition")]
- Distinguishes between "the screenshot is pretty" and "the screenshot tells the right story" [来源: sig + rsb]

## 5. Critique standards（评审标准 — 信号密度最高的分支）

### 5.1 Style guide critique
- "Are the keywords short (1-2 words each) and pressure-tested for redundancy?" [来源: rsb]
- "Are shape / color / texture systems specified separately, not bundled as 'mood'?" [来源: rsb]
- "Is there at least one DO/DON'T pair per principle?" [来源: sig (VFX guide style)]
- "Can a new artist join the project, read the guide, and produce in-style work without reviewer hand-holding?" [unverified]

### 5.2 Concept art critique
- "Does the silhouette read at thumbnail scale?" [unverified, 但行业标准]
- "If I removed color, does shape + value still carry the design?" [unverified, 但行业标准]
- "Where does this concept fit in the established shape vocabulary? Is it extending or violating?" [来源: rsb]
- "Does this concept inherit any pattern/element from existing IP, or is it floating free?" [来源: rsb]

### 5.3 0→1 阶段 critique
- "What's the north-star concept phrase? Is it a real phrase or a marketing tagline?" [来源: rsb]
- "Where's the v0.1 style guide?" — 没有就是 fail [来源: sig (Polydin step 2)]
- "Are we picking 'good enough' here? If so, what specifically would 'great' cost?" [来源: sig (Wayline)]

### 5.4 跨产品 / IP critique
- "Does this visual choice belong to this project, or could it belong to any project in our cluster?" — 后者是 commodity warning [来源: sig (Wayline distinctiveness)]
- "How does this read at the marketing screenshot test (1 frame, no context, target audience reaction)?" [来源: sig (Polydin "remember how it felt")]

## 6. Collaboration & communication

### 6.1 与 creative director
- Translates vague verbal vision into 3-7 keyword form for the team to act on [来源: sig (Naughty Dog AD scope: "shape the creative director's vision")]
- Pushes back on briefs without north-star concept phrases [来源: rsb]

### 6.2 与 artists / IC team
- Reviews work on the work, not on the artist [unverified]
- Provides constant feedback as work iterates, not only at milestones [来源: sig (Naughty Dog AD)]
- [unverified] Mentor mode: distinguishes "fix this specific thing" from "you need to develop this skill"

### 6.3 与 game design / engineering
- Writes briefs each adjacent department can act on without further translation [来源: sig (Polydin duty #3)]
- Knows when to compromise (engine constraint) vs hold the line (style integrity) [unverified]

### 6.4 与 marketing / PR
- Pre-approves marketing screenshots against style integrity before they ship [unverified]
- Can write the 1-paragraph "what this game looks like" copy [unverified]

## 7. Industry & business context

### 7.1 商业价值锚
- Knows that visual distinctiveness is a commercial requirement (steam store thumbnail discoverability), not luxury [来源: sig (Wayline)]
- Can articulate the brand value of style consistency in $-terms (lifetime customer recognition, merch viability, IP extension) [unverified]

### 7.2 团队规模 / 预算约束
- Knows what art style headcount + months are realistic to ship — and refuses ambition that exceeds it [来源: sig (Polydin pitfall #1)]
- [unverified] Can negotiate the "what's cuttable" list with creative director early, not at crunch time

### 7.3 平台 / 渠道差异
- Knows how the visual system needs to adapt for marketing surfaces (thumbnail / trailer / KV / store page) [unverified]
- [unverified] Aware of console / PC / mobile rendering differences for cross-platform titles

## 8. Ethics & failure modes

### 8.1 已知 0→1 失败模式
- "Cult of Good Enough" — accepting first-pass mediocre style to ship faster [来源: sig (Wayline)]
- Homogenization to industry trend (generic pixel-art / generic ArcaneⓇ / generic Studio Ghibli mimicry) [来源: sig (Wayline)]
- Reference-driven mimicry without a principle of departure [来源: sig (GDC)]
- Style guide deferred ("we'll write it once it stabilizes") — never stabilizes, team drifts [来源: sig (Polydin)]
- Mood-board-first decision making (lots of refs, no keywords) [来源: rsb]
- IP-from-scratch when existing assets could have grounded the new system [来源: rsb]
- Treating critique as personal taste rather than against documented standards [unverified]
- Visual complexity over distinctiveness (generic detail without identity) [来源: sig (Wayline)]

### 8.2 文化 / 表征伦理
- [unverified] Aware of cultural appropriation risks when drawing from real-world traditions (East Asian / Indigenous / etc.) without consultation
- [unverified] Knows when a character design risks stereotype reproduction vs respectful homage
