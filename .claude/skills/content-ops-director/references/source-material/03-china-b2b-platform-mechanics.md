## 核心机制事实

### 小红书 B2B
- **85% 企业采用双账号策略**：官方 + 创作者账号（市场部资深经理半官方身份）
- 创作者账号粉丝黏性 **3x 纯官方账号**
- AB 版内容（女性版场景化 / 男性版数据对比）转化率 +35%
- 平台搜索流量占比上升，关键词布局 + 投放成为标配

### 知乎 B2B
- 思想领导力转向打造**公司内部专家 IP**
- 长答案 + 专栏 + 高权重账号矩阵
- 搜索场景流量占比高（用户带具体问题来）

### 视频号 B2B
- 70% B2B 买家用视频辅助购买决策
- 视频号 + AI 工具链（脚本生成 / 剪辑 / 字幕）降低生产成本
- 微信生态闭环（视频号 → 公众号 → 企业微信 → SCRM）

### 抖音 B2B
- KOS（Key Opinion Sales）模式 — 销售个人 IP 化 + 直播
- 小橘案例：3 人小团队 1 年成交近 2000 万元 / 转化近 300 用户
- 留资链路（小风车 / 私信 / 私域承接）

## 对 capability map 的直接信号

- "国内平台机制" 分支必须有：
  - 小红书：双账号策略 + 半官方身份 + AB 版
  - 知乎：内部专家 IP 化 + 长答案搜索 SEO
  - 视频号：微信生态闭环 + AI 工具链
  - 抖音：KOS + 直播 + 留资链路
- "买家信任'人'胜过'品牌'"：海内外是同一机制（cross-region 共性 anchor）
- "Private domain 私域承接"：国内 B2B 标配（SCRM + 企业微信），海外对应是 newsletter + community

## 对 anchors 的直接信号

- **Sacred constraint 候选**：国内 B2B 内容不进私域 = 没闭环；海外不进 newsletter / community = 没续航
- **Stance 候选**：国内"个人 IP / KOS"与海外"employee-led / founder-led"是**同一机制的本地化变体**，不是两件事——director 应该看 mechanism 而不是 platform
- **Philosophy 候选**：B2B 内容运营总监的核心是搭"人-内容-私域"三角，不只是发内容
